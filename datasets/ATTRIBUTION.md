# Dataset attribution & licenses

The v2 benchmark reuses established public spatial-reasoning datasets. This file records the
source, license and the redistribution decision for each one. Code in this repository is MIT;
**each dataset keeps its own license**, and the converted task files / images are distributed under
that dataset's license with attribution — never under the repo's MIT license.

| dataset | source | license | redistribution in this repo |
|---|---|---|---|
| SpatialMQA (ACL 2025) | https://huggingface.co/datasets/liuziyan/SpatialMQA | CC BY 4.0 | **yes** — converted task file + images, attribution below |
| MindEdit-Bench | https://huggingface.co/datasets/ZODAOfficial/MindEdit-Bench | CC BY 4.0 | **yes** — converted task file + images, attribution below |
| Spatial457 (CVPR 2025) | https://huggingface.co/datasets/RyanWW/Spatial457 | Apache 2.0 | **yes** — converted task file + images (if published) |
| Spatial-DISE (ICLR 2026) | https://huggingface.co/datasets/TACPS-liv/Spatial-DISE | CC BY-NC-SA 4.0 | **annotations only** (CSV tables) under the same non-commercial share-alike terms; the 16 GB image shards are download-only |
| spatial3d (this project) | release asset `dataset_spatial_v3.tar` | CC BY 4.0 | yes (synthetic, this project) |

Published release assets: `v2.0-data-sources` (`mindedit_bench.tar`, `spatialmqa_full.tar`,
`spatial457.tar`, `spatialdise_annotations.tar`) and `v1.5` (`dataset_spatial_v3.tar`). Model weights,
frozen features and training/evaluation artifacts are **not** published.

## Required attribution

- **SpatialMQA** — Can Multimodal Large Language Models Understand Spatial Relations? (ACL 2025),
  dataset `liuziyan/SpatialMQA`, CC BY 4.0. Evaluation uses only the official dev/test split; the
  converted task file keeps the original question text and answer options.
- **MindEdit-Bench** — Benchmarking Object-Level Counterfactual Spatial Reasoning in VLMs from
  In-the-Wild Photos, dataset `ZODAOfficial/MindEdit-Bench`, CC BY 4.0. Three-view indoor triplets;
  images are decoded from the official parquet release.
- **Spatial457** — Spatial457: A Diagnostic Benchmark for 6D Spatial Reasoning of Large Multimodal
  Models (CVPR 2025), dataset `RyanWW/Spatial457`, Apache 2.0. The official release (images, 3D-asset
  archive, `Spatial457.py`) is mirrored as `spatial457.tar`. Its question/answer pairs are generated by
  that official pipeline from the 3D assets, so unified T2 tasks are **not** published yet; run the
  official generator to produce them.
- **Spatial-DISE** — A Unified Benchmark for Evaluating Spatial Reasoning in Vision-Language Models
  (ICLR 2026), dataset `TACPS-liv/Spatial-DISE`, **CC BY-NC-SA 4.0**. Only the annotation CSV tables
  are mirrored in the `spatialdise_annotations.tar` release asset, under the same non-commercial
  share-alike terms; the 16 GB image shards are not mirrored and must be downloaded from the
  original source. Any use here is non-commercial; redistribution must keep this license and
  attribution.

## Rules for derived data

- Converted task files are `dataset`-scoped and carry the `dataset` field; scores are always
  reported per dataset, never mixed into one unlabeled pool.
- If a dataset's license changes or forbids redistribution, only the download + conversion script is
  kept here; existing release assets must be removed accordingly.
- No dataset is used to train the organizers' model; evaluation files are frozen and hashed.
